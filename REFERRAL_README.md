# Referral и бесплатные разборы

Реферальная программа использует canonical-таблицы Supabase: `referral_codes`, `referrals`, `referral_rewards` и `free_analysis_ledger`.

Переход по ссылке и регистрация только прикрепляют пользователя B к пользователю A. Начальный бесплатный разбор создаётся сервером один раз при обращении к `GET /api/free-analysis`; клиентские флаги и `localStorage` для этого не используются.

Использование бесплатного натального разбора фиксируется после успешного сохранения карты через `POST /api/free-analysis/consume`. Сервер проверяет владельца карты и вызывает RPC `consume_free_analysis` с постоянным ключом `analysis:chart:<chart_id>:<user_id>`. Повтор запроса не списывает кредит повторно.

После успешного списания сервер квалифицирует pending referral B, создаёт доступный reward для A и запись `referral_reward` в ledger A. Уникальные ограничения referral и idempotency key защищают от повторной выдачи бонуса при повторных запросах.

Баланс рассчитывается как сумма `free_analysis_ledger.amount`. Premium и бесплатный разбор — разные возможности: бесплатное использование не меняет `charts.premium` и не затрагивает платежи.
