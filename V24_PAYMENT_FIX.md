# V24 — единый API для ПК и телефона

Исправлено:
- Vite проксирует `/api` на backend `8787`, поэтому браузер больше не ходит напрямую на `192.168.3.3:8787`.
- Premium использует относительный `/api` по умолчанию.
- Возврат из ЮKassa теперь строится из фактического origin браузера, а не всегда из `localhost`.
- Карты аккаунта читаются/создаются/удаляются через backend с service-role. Это убирает зависимость интерфейса от RLS `charts`.
- CORS разрешает localhost и LAN-адреса `192.168.x.x:5173`.

Запуск:
```powershell
npm.cmd install
npm.cmd run dev -- --host 0.0.0.0
```
Во втором терминале:
```powershell
npm.cmd run server
```
Телефон в той же Wi-Fi сети открывает `http://192.168.3.3:5173`.
