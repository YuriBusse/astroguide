# AstroGuide — исправленная версия Premium / Supabase / YooKassa

## Что исправлено

1. Добавлено автоматическое обновление Supabase access token через refresh token.
2. Облачные карты, сохранение и удаление теперь получают актуальную сессию перед запросом.
3. Premium status, создание платежа и проверка платежа используют актуальный токен.
4. Сохранение новой карты больше не блокируется из-за просроченного access token.
5. Исправлена отправка JSON при отмене заказа после ошибки YooKassa.
6. `.env` с секретами не включён в этот ZIP. Используйте `.env.example` как шаблон.
7. `node_modules` не включён в ZIP — зависимости должны быть установлены на вашей машине.

## Запуск

Откройте терминал в папке проекта:

```powershell
npm.cmd install
npm.cmd run dev -- --host 0.0.0.0
```

Во втором терминале:

```powershell
npm.cmd run server
```

После этого откройте:

`http://localhost:5173`

## Настройка .env

Скопируйте `.env.example` в `.env` и вставьте реальные:

- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `YOOKASSA_SECRET_KEY`

Секретные ключи не должны начинаться с `VITE_`.

## Проверка backend

```powershell
curl.exe http://localhost:8787/api/health
```

Ожидается:

```json
{"ok":true,"supabaseConfigured":true,"yookassaConfigured":true,"port":8787}
```

Если `yookassaConfigured` = `false`, проверьте `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.

## Важное

Если раньше `.env` или секретный ключ YooKassa отправлялся в ZIP/чат/Git, для production лучше перевыпустить секретный ключ YooKassa и server-role ключ Supabase.
