Готовый фронтенд-прототип сервиса натальных карт.

## Запуск

В PowerShell, если `npm` блокируется политикой выполнения скриптов, используйте:

```powershell
npm.cmd install
npm.cmd run dev
```

Если хотите один раз разрешить обычный `npm`:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Что в V3

- центрированный hero-блок «Узнай свою натальную карту»;
- широкая desktop-версия страницы;
- большая натальная карта;
- точные положения планет сохраняются по долготе;
- близкие планеты визуально разводятся по радиусам без изменения их градусов;
- аспекты строятся по реальным точкам долгот, а не по смещённым иконкам;
- ASC, DSC, MC и IC показываются по фактическим углам карты;
- ASC и MC вынесены в отдельные карточки статистики;
- таблица планет: знак, градус, дом;
- выбор из популярных городов России с координатами и часовыми поясами;
- адаптивная мобильная версия;
- расчёты планет и домов через Swiss Ephemeris.
