# AstroGuide V26 — Premium report redesign

## Что изменено

- Полностью переработан Premium-отчёт как персональный продукт, а не длинная лента текста.
- Добавлена обложка отчёта с кратким описанием карты, статусом Premium и статистикой.
- Добавлен блок «Главное» в самом начале с тремя прикладными выводами.
- Добавлена боковая навигация по разделам на desktop и горизонтальная навигация на мобильных.
- Перестроен порядок: Главное → Основа карты → Личность → Отношения → Карьера → Деньги → Развитие → Аспекты → Финал.
- Планетные иконки заменены с Unicode-символов на настоящие inline SVG-глифы, чтобы они одинаково отображались в браузерах и не зависели от шрифтов.
- Для каждого тематического раздела усилена визуальная иерархия: ключевая мысль → контекст → сильные стороны → зоны внимания → практические выводы → следующий шаг.
- Добавлен финальный блок «Что взять с собой из отчёта».
- Сохранена адаптация для мобильных устройств.

## Важное

Сборка в этой среде не запускалась, потому что `node_modules` отсутствует и установка зависимостей недоступна. На локальном компьютере после распаковки выполните `npm.cmd install`, затем `npm.cmd run build`.

`.env` в архив не включён.
